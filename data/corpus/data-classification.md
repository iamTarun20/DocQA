# Data classification and storage

Classify Northwind Labs work when it is created or first received. The available labels are Public, Internal, Confidential and Restricted. The owner chooses the highest label that applies to any content in the file. The label follows the information when it is copied into slides, exported as a spreadsheet or embedded in a ticket.

Restricted records must be stored in Boreal Vault. Customer credentials, unreleased designs subject to special contract terms and encryption recovery materials are examples of Restricted content. Add the owner's role and retention category when depositing a record. If the upload contains several files, check the access list before granting a group permission to the folder.

Confidential documents can be stored in an approved team workspace with named membership. Internal material can be shared across the company when there is a business reason. Only approved Public releases can be posted to an external site. Redacting a file does not change its label until the data owner checks the redaction and records the decision.

When a recipient cannot open a file, request a permission review rather than moving the file to a less restricted workspace. Temporary copies created for a migration inherit the source label and should be removed after verification. Security Operations can help identify where an unexplained copy came from. Include the original owner, destination and transfer date when reporting a labeling mistake.
