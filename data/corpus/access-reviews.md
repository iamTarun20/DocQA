# Access certification reviews

Each quarter, Northwind Labs sends application owners a list of active staff, service accounts and role assignments. The owner confirms business need with the user's manager and records the decision in Gatehouse. An account whose role changed during the quarter should be reviewed against current duties. Reviewers can attach the approved access request to show why an uncommon permission is still needed.

Managers must complete their access review decisions within 7 business days of receiving the review notice. Gatehouse sends an automatic reminder halfway through the window. A manager who will be away should name a temporary reviewer in the case before leaving. If the case has no owner, the application administrator routes it to the department head.

Marking an entitlement for removal creates a fulfillment ticket for the application owner. For a privileged role, Security Operations verifies removal against the application's own activity log. A manager can file a new access request if a role needs to be restored after review. Keep the review outcome separate from the replacement request so the access history can be reconstructed.

The review cycle closes once all cases have either been certified or assigned an exception. Exceptions include an owner, a reason and a date for another check. The program coordinator samples finished cases for role descriptions that are too vague to support a decision. Update those descriptions before the next list is distributed.
